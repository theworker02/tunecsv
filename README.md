# tunecsv

Tune color csv values and contrast-safe presentation helpers.

**Site:** https://theworker02.github.io/tunecsv/

## Install / run

```bash
git clone https://github.com/theworker02/tunecsv.git
cd tunecsv
node src/cli.js
node --test
```
